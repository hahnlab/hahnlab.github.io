Recombinant Population Genome Construction (RPGC)

This page describes some of the tools that can be used to construct an accurate genome assembly by sequencing a recombinant population (what we call RPGC).

The general outlines and constraints of the method are discussed in this paper.

A manual describing the step-by-step instructions for repeating the analyses described in the above paper can be found here.

A folder containing all the configuration files, python scripts, and example inputs can be found here.

All of the simulated data used in the paper have been deposited here.
